# AWS-Machine-Learning-Systems-C02-Topics
My Learning Experience: AWS Machine Learning MLA-C02 Certificate - Notes - Progress - Videos - Information

Hello, I'm Marcin Hoffman, and this is my documentation for my Machine Learning Certificate MLA-C02 offered through AWS services. This repository will hold my notes as I work through the process.

I wanted to share this publicly because I felt that if I were to apply what I was learning and have to go over it multiple times to be able to properly discuss and present the information, it would help me understand the concepts and applications more thoroughly,
Second, from a previous certificate, I found other people's notes quite useful, and I wanted to see if I could do the same for others. 

What is in the repository?

A record I'll update every two weeks with a variety of topics from the certificate until I finish the final exam.

Each two-week segment is a BLA(Biweekly Learning Artifact) and will be titled as such.

Each folder will contain my notes, presentations, videos, and anything else I add later as part of the BLA.

The README is there so you're familiar with the repository and the basic idea behind what is being stored and created.

I won't reproduce any course content; these will all be my own creations, with lots of information coming from the Udemy online course. This is meant for educational and learning purposes, so there may be mistakes and misleading information; please be aware.
